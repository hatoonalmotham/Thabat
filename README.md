# ثبات

تطبيق ويب بسيط لمتابعة العادات اليومية.

- **اليوم**: رسالة كتبتها لنفسك أمس، والتأشير على الصلوات الخمس وعاداتك، وكتابة رسالة لنفسك غدًا.
- **إضافة عادة**: أضف عادات جديدة باسم ورمز، أو احذف ما لا تحتاجه.
- **المتابعة**: ستريك أيام الثبات، ونقاط ومستويات، وأوسمة، وخريطة لآخر ٥ أسابيع، ومتابعة كل عادة.

التطبيق ملف واحد `index.html` بلا خادم، والبيانات محفوظة في متصفحك. يدعم الوضعين الداكن والفاتح، ويستخدم [خط ثمانية](https://thmanyah.com/font).

## التشغيل

افتح `index.html` في المتصفح.
